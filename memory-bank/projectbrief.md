# Project Brief

`nextjs16-t3-template` is a ready-to-use full-stack web application foundation. It delivers authenticated user access, a PostgreSQL-backed data layer, typed API procedures, reusable forms and UI, theme switching, maintenance mode, and production-oriented quality checks.

Documentation should describe how the application works and how to operate it. Treat the current source, Prisma schema, environment schema, and package scripts as the authority; avoid describing it as an empty starter or documenting features that are not implemented.
